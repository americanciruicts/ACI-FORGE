## How Login Works (SSO Flow)

1. All users log in through **ACI FORGE** (aci-forge.vercel.app)
2. Going to NEXUS or KOSH directly redirects to FORGE login
3. After FORGE login, SSO token redirects the user back to the requested app
4. **One password** — the FORGE password is the only one needed
5. Admin can reset any user's password from FORGE User Management
